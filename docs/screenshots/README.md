# Dashboard Screenshots

This directory contains screenshots of all the dashboards in the Tandil platform.

## Required Screenshots

Please add the following screenshots with the exact filenames:

1. **admin-dashboard.png** - Admin Dashboard screenshot
2. **client-dashboard.png** - Client Dashboard screenshot
3. **hr-dashboard.png** - HR Dashboard screenshot
4. **technician-dashboard.png** - Technician Dashboard screenshot
5. **supervisor-dashboard.png** - Supervisor Dashboard screenshot
6. **area-manager-dashboard.png** - Area Manager Dashboard screenshot

## How to Add Screenshots

1. Take screenshots of each dashboard while logged in with the respective role
2. Save them as PNG files with the naming convention above
3. Place them in this directory (`docs/screenshots/`)
4. Recommended dimensions: 1920x1080 or 1280x720
5. Ensure screenshots show the main dashboard view clearly
